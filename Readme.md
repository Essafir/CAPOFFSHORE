# Capofishore

A simple and responsive landing page with a working contact form.

## Tech Stack

* **Front-End:** HTML5, CSS3, JavaScript, Bootstrap 5, Bootstrap Icons
* **Back-End:** PHP
* **Environment:** XAMPP (Apache)
